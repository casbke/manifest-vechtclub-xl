# Foto's van de koffiezaken

bestand met de juiste naam in deze map staat — geen code aanpassen nodig.

## Tips

- `.jpg` werkt; `.jpeg`, `.png` en `.webp` worden ook automatisch geprobeerd.
- Liggend (landscape) ziet er het mooist uit — het fotovlak is ~16:10.
- Gebruik eigen of rechtenvrije foto's. Voor **Hotel âme** graag foto's van het
  café-gedeelte, niet van de hotelkamers.
- Zolang er nog geen foto staat, toont de kaart een nette koffie-placeholder (☕).
